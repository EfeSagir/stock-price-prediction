# Amazon Stock Price Prediction with PyTorch (LSTM vs. GRU)

## Description

A time-series price prediction project built with PyTorch. Historical daily
Amazon (AMZN) stock data (Jan 2021 – Dec 2025) is cleaned, turned into
sliding-window sequences, and used to train and compare two recurrent
architectures — an LSTM and a GRU — on predicting the next day's closing
price.

## Usage

### 1. Preprocess the data

```bash
python data/processed/preprocess.py
```

Strips whitespace from column names, converts the `Price` column to float,
sorts rows chronologically (oldest → newest), and saves the result to
`data/processed/AMZN_clean_prices.csv`.

### 2. Explore in the notebook (optional)

```
notebooks/amzn_stock_prediction.ipynb
```

Reads the cleaned CSV, builds sliding windows (lookback = 20), trains an
LSTM and a GRU for 60 epochs, and plots predictions against actual prices.
This notebook is for exploration — `predict.py` below is the standalone
pipeline.

### 3. Train & evaluate from the command line

```bash
python predict.py
```

Loads and cleans the raw CSV directly (via `scripts/dataset.py`), trains
an `LSTMModel` and a `GRUModel` (both `num_layers=2`, 60 epochs, lr=0.01),
prints the RMSE for each on the test set, and shows a plot of actual vs.
predicted prices via `results/results.py`.

## Results

RMSE is printed to the console after running `predict.py`, comparing the
LSTM and GRU models on the held-out test set (most recent ~20% of the data,
chronologically after the training set).

## Limitations

- Trained and evaluated on a single ticker (AMZN); generalization to other
  stocks has not been tested.
- Only the `Price` (close) column is used as a model input — `Open`,
  `High`, `Low`, `Vol.`, and `Change %` are present in the data but not
  currently used as features.
- No technical indicators (moving averages, RSI, etc.) or external data
  (news, sentiment) are included.
- The notebook and `predict.py` are two independent pipelines with
  slightly different hyperparameters (e.g. `hidden_dim=64` in the notebook
  vs. `hidden_dim=32` in `predict.py`) — intentional for now, but worth
  keeping in sync if one is updated.
- Predictions have not yet been benchmarked against a naive baseline
  (e.g. "predict tomorrow = today's price").
